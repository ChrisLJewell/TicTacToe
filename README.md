# Tic-Tac-Toe Web App

A clean, interactive browser-based implementation of the classic **Tic-Tac-Toe** game, built using vanilla JavaScript, HTML, and CSS. It features dual game modes (Player vs. Player and Player vs. AI), dynamic turn indicators, a game timer, and local win-state tracking.

🔗 **[View Live Demo](https://chrisljewell.github.io/TicTacToe/)** | 📂 **[View Source Code](https://github.com/ChrisLJewell/TicTacToe)**

---

## ✨ Features

*   **Two Game Modes:**
    *   **Player vs. Player (PvP):** Pass-and-play local multiplayer.
    *   **Player vs. AI:** Play against a randomized computer opponent (`makeAIMove`).
*   **Dynamic UI & Turn Tracking:** Automatically updates status text and custom color-coded highlights for Player X and Player O.
*   **Built-in Game Timer:** Measures and displays how long each match takes to complete.
*   **Responsive State Handling:** Automatically locks the board upon a win, loss, or tie, and triggers a prompt to play again.
